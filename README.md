Project Workflow

Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX Calculations → Data Visualization → Business Insights

1. Data Collection

Imported the cafe sales dataset into Power BI.

2. Data Cleaning

Used Power Query to:

Remove unnecessary data
Handle missing values
Correct data types
Standardize columns
Prepare the dataset for analysis
3. Data Analysis

Created calculated columns and measures using DAX to generate important business metrics.

4. Dashboard Development

Designed an interactive Power BI dashboard using charts, cards, slicers, and other visualizations.

5. Business Insights

Analyzed the dashboard to identify sales trends, product performance, and customer purchasing patterns.
